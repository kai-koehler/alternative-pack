# Alternative Pack

Pick the mainstream apps you used before, show the alternatives you've switched to, and share your pack as an image.

A static web page (plain HTML, CSS and JavaScript, no build step). Open `index.html` or serve the folder with any static file server. Live at [tools.kai-koehler.com/alternative-pack](https://tools.kai-koehler.com/alternative-pack/).

App catalog and logos from [PrivacyPack](https://privacypack.org) by Ente (MIT), see `LICENSE` and `LICENSE-privacypack.txt`.
